# 选项卡片回传 Markdown 化（deferred 消息排版升级）

## Goal

选项卡片回传消息（deferred 通道投递的 `hana-background-result`）从纯文本平铺改为 Markdown 标题结构。deferred 通道投递的消息体支持 Markdown 渲染，升级后 Agent 侧（模型可见）与调试侧（日志/回放）的信息层级更清晰：

- 大标题立身份：`# 选项卡片` 一眼识别消息来源
- 两个小标题下放正文：`## 问题` / `## 回答` 各带一段正文，问题与选择分离，不再挤在同一行

## Non-Goals

- 不改 deferred 投递机制（register/resolve、trigger_parent_turn、消费标记时机全部不动，继承 0.8.10 契约）
- 不改卡片渲染/消费落库（option_cards 表、SSR、消费锁定态不动）
- 不改 Agent 侧识别锚点本身：「选项卡片」身份标记保留，`跳过，不做选择` 短语保留；仅移除 `我选择：` / `自定义输入：` 冗余前缀（选项与自定义统一为回答正文纯内容），只改排版结构
- 不动历史卡片（旧卡片走同一 POST /card/choose，服务端统一生成新格式，无分支）
- 不引入新依赖

## Acceptance Criteria

- [ ] `POST /card/choose` 三种模式回传文本均为 Markdown 标题结构（选项与自定义同构，skip 保留短语）：
  - option / custom：`# 选项卡片\n\n## 问题\n<q>\n\n## 回答\n<内容>`（回答正文直接放用户内容，不加模式前缀）
  - skip：`# 选项卡片\n\n## 问题\n<q>\n\n## 回答\n跳过，不做选择`
- [ ] 「选项卡片」大标题作为身份标记，Agent 以「消息含 # 选项卡片 标题」判定卡片回传
- [ ] 工具描述（tools/option-card.js）、注入规则（rules/选项卡片规则.md）同步新格式说明
- [ ] README 版本历史新增 0.8.11 条目；manifest 版本 0.8.10 → 0.8.11
- [ ] 打包产物更新（releases/rules-injector-0.8.11.zip）
- [ ] 实测（需宿主重启后）：点击选项/自定义/跳过，Agent 收到 `# 选项卡片` 结构的 hana-background-result，识别为选择结果并接续处理

## Boundary Conditions

- **宿主重启前**：插件目录已更新但宿主未重载，实测不可行（本次不做运行时验证，交付后由用户重启验收）
- **旧 Agent 会话（识别契约已注入旧格式描述）**：新格式消息到达时，若 Agent 按旧契约识别，「选项卡片」身份标记与「跳过，不做选择」短语仍保留，选项/自定义内容虽无前缀但可依「## 回答」小标题推断语义；重启后注入的新规则文档保证识别一致
- **q 与 choice 含 markdown 特殊字符**：原样拼接不转义（q 来自卡片标题、choice 来自用户输入，均为单行短文本；标题含 `#` 等符号概率极低，不额外处理，与 0.8.10 相同的信任边界）

## Constraints

- 零新依赖；沿用 deferred 通道（bundle 0.446.6）
- 版本 0.8.10 → 0.8.11
- 回传文本以库中 q 为权威（不变），库无记录回退 body 字段（不变）

## Design Decisions

- **为什么用标题结构而非加粗/引用块**：用户指定「大标题表明身份，两个小标题下放正文」。`#` 身份 + `##` 信息块是 Markdown 语义化结构，渲染层级清晰；比加粗/行内代码更利于长问题、长自定义输入的可读性。
- **标题层级选择**：`# 选项卡片` 大标题（不带括号，简洁，身份即标题）；`## 问题` / `## 回答` 两个小标题（参考用户给定结构，三级标题不必要）。
- **模式合并（选项/自定义去前缀）**：点击选项与自定义输入本质同为「用户的一段文本回答」，「## 回答」小标题已表达语义，`我选择：` / `自定义输入：` 前缀是冗余，删除（极简）；Agent 无需区分两种模式，回答正文即内容。跳过不是文本回答而是放弃操作，保留「跳过，不做选择」短语避免与内容混淆。
- **识别契约延续**：「选项卡片」四字仍为消息身份标记（从行首括号前缀变为大标题），Agent 侧「消息含『选项卡片』标记 = 卡片回传」判定语义不变；「跳过，不做选择」短语原文保留。
- **格式变更需重启生效**：插件工具描述与注入规则在宿主启动时加载，更新插件目录后必须重启宿主才能让 Agent 侧识别到新格式描述；本次交付不包含运行时验证。
