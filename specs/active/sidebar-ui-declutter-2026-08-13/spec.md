# Spec: Sidebar UI 信息精简（sidebar-ui-declutter）

日期：2026-08-13
状态：spec（待对焦确认）

## Goal

精简 rules-injector 侧边栏规则列表的信息密度：去掉与开关、分组重复的状态文字和来源标签，规则行只保留必要信息；精简说明区块文案。纯前端模板改动，不动后端与注入语义。

## Non-Goals

- 不做视觉风格调整（透明融入纸张背景、字号层级重排）——独立方向，另行立项
- 不做交互优化（展开状态保留、删除二次确认、操作反馈强化）——独立方向，另行立项
- 不改后端 API、数据结构、指纹/注入逻辑

## Acceptance Criteria

- [ ] AC1 规则行不再显示「生效中/已停用」状态文字
- [ ] AC8 禁用规则标题弱化显示（text-muted 灰），启用规则标题正常色——状态文字删除后的补充视觉线索
- [ ] AC2 分组内不再显示来源标签：builtin 组无「内置」、custom 组无「自编」
- [ ] AC3 「被覆盖」标签保留：仅当 custom 与 builtin 同名（overridden=true）时显示
- [ ] AC4 规则行精简为：展开箭头 + 标题 +（被覆盖标签）+ 开关
- [ ] AC5 说明区块文案精简为一句开关语义（.md 启用 / .mdisabled 停用）
- [ ] AC9 「规则文件」分组标题删除，规则列表直接跟随注入开关分组
- [ ] AC10 禁用文件命名为整体扩展名 `.mdisabled`（xxx.md ↔ xxx.mdisabled）；旧式 `xxx.disabled` / `xxx.md.disabled` 不属于新命名（扫描忽略），手动清理，代码不做历史形态兼容
- [ ] AC6 功能不回归：开关/展开/编辑/保存/删除/恢复默认/新建全部可用（宿主实测）
- [ ] AC7 展开区保留文件名显示（编辑时定位文件需要）

## Boundary Conditions

- custom 组为空时正常显示（无）占位，不破版
- 规则名超长时标题换行/截断不挤压开关
- 被覆盖规则在 custom 同名删除后，overridden 标记自然消失（数据驱动，无需特判）
- 禁用规则仍可展开查看内容（开关 ≠ 展开权限）

## Constraints

- 只改 `routes/sidebar.js` 的 WIDGET_CSS / WIDGET_JS / HTML 模板，不动 `/sidebar/*` API 路由
- 不引入新依赖
- 保持 Hana 设计规范：宿主 CSS 变量、无渐变、无 emoji、无阴影光效

## Design Decisions

### D1 状态表达 = 开关 + 标题弱化（双通道，不冗余）

状态文字「生效中/已停用」是开关的重复信息，删除。状态由两通道表达：开关位置（开/关）+ 禁用规则标题变灰（text-muted）作为弱化提示。开关是主表达，标题颜色是辅助线索，二者互补不重复。

被拒绝：纯靠开关表达（Nyaser 确认需要弱化提示）；保留状态文字（与开关重复）。

### D2 来源信息归并到分组

分组标题「内置规则 / 自定义规则」已表达来源，行内「内置/自编」标签删除。仅 overridden（custom 覆盖 builtin）保留「被覆盖」标签（stamp 色），因为这是跨分组的衍生状态，无法由分组表达。

### D3 说明区块精简

原文案含数据流细节（种子 → 工作副本、升级策略、扩展名机制），压缩为一句：「规则开关 = 文件扩展名（.md 启用 / .mdisabled 停用）；内置规则可恢复默认，自定义规则可自由增删改。」技术细节由「规则管理规则」注入文本承载，侧边栏只留操作语义。

### D4 顶栏 badge 保留

「注入中 / 已暂停」在头部，是全局总开关的快速状态指示，位置独立、有速览价值，保留不动。

### D5 禁用命名 = 整体扩展名 .mdisabled（对焦补充决策，0.8.2 修订）

开关命名最终定为 `xxx.md` ↔ `xxx.mdisabled`。中间态曾考虑 `.md.disabled`（0.8.1），但实测发现它含 `.disabled` 后缀：旧版 toggleRule 的 `endsWith('.disabled')` 误匹配后 replace 拼接产生双重扩展名 `xxx.md.md`（本会话实测复现，注入清单出现重复规则）。`.mdisabled` 是整体扩展名，不以 `.md` 结尾、不含 `.disabled` 后缀，新旧代码均无误匹配路径，从根上消灭双重扩展名歧义。旧式 `xxx.disabled`（0.8.0/第一版 0.8.1）与 `xxx.md.disabled`（第二版 0.8.1）不属于新命名，扫描时忽略，由手动清理（Nyaser 决策：代码不留历史形态兼容）。

### D6 「规则文件」分组标题删除（对焦补充决策）

「注入开关」分组之后的规则列表区，内容语义已自明（规则 + 新建入口），分组标题是多余层级，删除。

## 对焦确认记录（2026-08-13）

- 禁用状态表达：保留弱化提示——禁用规则标题变灰（AC8，D1 修正版）
- 命名方案：整体扩展名 `.mdisabled`（Nyaser 拍板；`.md.disabled` 实测产生双重扩展名歧义后淘汰，AC10/D5 修订版；旧形态文件手动清理，代码不兼容）
- 「规则文件」分组标题：删除（AC9/D6）
